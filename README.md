# En Sintonía con Jesús — PWA

Aplicación web progresiva gratuita para iPhone, iPad y Android. No es un archivo IPA ni una aplicación nativa de App Store.

## Publicar GitHub Pages
1. En el repositorio abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige **main** y **/(root)**; guarda.
4. Espera a que GitHub Pages publique el sitio.

URL prevista: https://radioensintoniaconjesus-ship-it.github.io/radio-en-sintonia-pwa/

## Instalar
- **iPhone/iPad:** abre la URL en Safari → Compartir → Agregar a pantalla de inicio.
- **Android:** abre en Chrome → menú ⋮ → Instalar aplicación o Agregar a pantalla principal.

## Límites técnicos
La interfaz puede guardarse en caché, pero el audio y las publicaciones requieren internet. La app consulta Blogger al abrirse; no envía notificaciones automáticas. La reproducción en segundo plano/pantalla bloqueada depende de Safari/iOS y debe probarse en un iPhone real. El icono SVG es compatible con navegadores modernos; iOS puede generar el icono de inicio de forma distinta. Para un icono Apple específico conviene añadir un PNG 180×180.

La PWA no solicita ubicación, contactos, cámara ni cuenta de usuario.
